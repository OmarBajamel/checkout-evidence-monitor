# Checkout Evidence Monitor

**مساحة عمل محلية لفهم التغيّرات في مسار إتمام الشراء ومراجعة أدلتها.**

[English](README.md) · العربية · [Deutsch](README.de.md)

[ابدأ هنا](docs/ar/GETTING_STARTED.md) · [فهرس الأدلة](docs/README.md) · [ملاحظات الإصدار](docs/releases/v0.2.0-alpha.1.md) · [خطة التطوير](docs/ROADMAP.md)

> **الإصدار 0.2.0 أولي — التنفيذ موجود، والتحقق التشغيلي لم يكتمل بعد.** اجتازت النسخة فحوص الكود والأنواع والبناء. ما زالت المراقبة ومسار PILOT وواجهة Signal بحاجة إلى الاختبار التشغيلي والبصري. نتائج الإصدار السابق لا تثبت جاهزية هذه النسخة.

## افهم التغيّر قبل أن تحكم عليه

يساعد المشروع مشغّل المتجر المصرّح له على مقارنة الزيارات المسجّلة، وربط التغيّرات بسياقها، وتوثيق قرار المراجعة مع الأدلة. ويضم بيئة اصطناعية منفصلة لتجارب بحثية قابلة للتكرار.

**إعداد، ثم رصد، ثم مقارنة وفحص، ثم توثيق القرار.**

ظهور برنامج نصي جديد لا يعني أنه ضار، وغياب الدليل لا يثبت الأمان. ربط الملاحظات بالمعايير لا يُعد شهادة امتثال.

## ما الذي تتضمنه النسخة؟

- أربع واجهات مترابطة: التقييمات `Assessments`، ومسار الزيارة `Journey`، والتغيّرات `Changes`، والأدلة `Evidence`.
- إعداد موجّه للوجهات والصفحات المسموحة، ومحددات العناصر المرئية، ونطاق التفويض ومدته؛ تُحفظ الإعدادات بحالة متوقفة.
- مقارنة السجل المرجعي بالزيارة اللاحقة، مع بصمات المحتوى والترويسات وخصائص ملفات الارتباط وحدود الرصد.
- جدولة محلية، وإيقاف وإلغاء، ومعالجة الزيارات المنقطعة والمواعيد الفائتة.
- صندوق تنبيهات داخل التطبيق، وسجل قرارات لا يعدّل الملاحظات الأصلية، وتصدير للمراجعة بعد تنقيح البيانات.
- بيئة `LAB` اصطناعية وأدوات بحث وتقارير HTML وJSON وCSV.

## أنماط العمل وحدودها

| النمط | الغرض | الحد الأساسي |
|---|---|---|
| `OFFLINE` | مراجعة سجلات مستوردة أو أمثلة اصطناعية | لا يجمع صفحات بالمتصفح |
| `LAB` | تجارب اصطناعية قابلة للتكرار | سيناريوهات المشروع داخل حاوية معزولة عن الشبكة |
| `PILOT` التجريبي | رصد صفحات HTTPS عامة ومصرّح بها | وجهات ومسارات محددة، وجلسة ضيف جديدة، وطلبات GET/HEAD فقط |

لا يسجّل PILOT الدخول، أو يملأ النماذج، أو يعدّل السلة، أو ينشئ طلبات، أو ينفّذ مدفوعات. لا تُضبط موافقة التتبع تلقائيًا، وقد يحد ذلك من الوصول إلى بعض الصفحات. لا يعد المشروع بتغطية جميع المتاجر بمجرد إدخال رابط.

## ابدأ محليًا

يتطلب إعداد المصدر **Python 3.12 وNode 24 وGit**. تحتاج إلى Docker للجمع، وليس لمراجعة OFFLINE. لا تتطلب الوظائف الأساسية حسابًا سحابيًا أو واجهة خاصة بالمتجر أو خدمة مدفوعة أو نموذجًا لغويًا.

يشرح [دليل الإعداد بالعربية](docs/ar/GETTING_STARTED.md) خطوات Windows وLinux وتشغيل العرض الاصطناعي بإذن صريح. فتح مساحة العمل العادية لا يبدأ الجمع. تشغيل المراقبة قرار مستقل، وزيارة متجر فعلي تتطلب تفويضًا محدد الوجهات والإجراءات والمدة.

راجع [ملاحظات الترقية](docs/UPGRADING.md) قبل استخدام مخزن أدلة موجود، ثم [دليل التجربة المحدودة](docs/PILOT_QUICKSTART.md) و[حدود الأمان](docs/PILOT_SECURITY.md).

## حالة التحقق والبحث

فحوص الكود والأنواع والبناء ناجحة. اختبار التشغيل والعزل والواجهة وتوافق المتاجر ما زال معلقًا، ولم تُجرَ دراسة مستخدمين لهذه النسخة.

تخص الاختبارات والتجارب السابقة إصدار v0.1.0 وحده. يوضح [سجل التحقق](docs/TESTING_STATUS.md) تفاصيلها وحدودها، ويفصل [البروتوكول الجديد](docs/EVALUATION_V1_1.md) إعادة التجارب الاصطناعية عن ضوابط التجربة العملية وفهم المستخدم للنتائج.
