# Signal 03 assets

Current visual identity for the 0.2.0 alpha.

The original open-aperture mark connects a journey segment to a recorded evidence point. It is not a shield, seal, certification badge or claim of security. Blue #4F5BFF, night #0B1020, lime #DDFB72 and canvas #F3F5FA define the core palette.

Preserve the mark's proportions, colors and clear space. README hero is 1600×800; social artwork is 1280×640. These are original illustrations, not screenshots. The two concept images contain synthetic design fixtures and must always be labelled as Figma concepts.

The assets were exported from the owner's approved Signal design on September 29, 2026. manifest.json records each byte hash. The source implementation uses system font fallbacks; no font binary or complete third-party UI kit is distributed. Lucide icons and Material 3 component foundations remain separately attributed in the project notices.

Composite concept images retain Material 3 Design Kit attribution to Google under Figma's free Community CC BY 4.0 terms. See [the source and modification notice](../../THIRD_PARTY_NOTICES.md#signal-integration-september-2026). Original brand artwork remains MIT.
