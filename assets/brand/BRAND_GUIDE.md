# Checkout Evidence Monitor identity

The mark is an original stepped journey entering an open evidence frame. Its opening expresses incomplete observation; the final square is a recorded point, not a certification seal. Descriptor: “See the change. Follow the evidence.” No trademark clearance or external endorsement is claimed.

Use the teal mark/ink wordmark on white or warm canvas, monochrome on simple light backgrounds and the reversed mark on dark teal/ink. Preserve one quarter of the mark width as clear space. Intended minimum mark size is24px, favicon32px; inspect actual rendering at smaller contexts before claiming legibility. The wordmark remains editable system text, so metrics can vary with fallback fonts. PNG lockup is the fixed production rendering. Do not stretch, add shield/seal ornaments or combine with OWASP/PCI/ISO logos.

Palette and component rhythm are in tokens.json, synchronized with the original UI design authority. UI font: system-ui/Segoe UI/sans-serif. Evidence: platform monospace. No font files are distributed. Spacing unit4px; controls use6px radius and explicit focus rings. Status requires text and icon, not color alone.

Editorial artwork uses48px outer margins, consistent serial/header/footer treatment and different compositions: journey, evidence tiers, change/evidence concept, capture chain, method matrix and release boundary card. Keep DESIGN CONCEPT labels intact. Status captions must match the linked verification or publication record. Method diagrams describe the observation arms; they are not application screenshots.

Original artwork is MIT. Asset paths, dimensions, hashes, creation method, alt text and review status are in asset-register.json. The 1200×627 and1080×1350 post sizes are production choices, not claimed platform requirements. Images were inspected as inert artwork; bounded local app visual review is documented in docs/TESTING_STATUS.md. Public concept artwork remains separate from runtime evidence.
