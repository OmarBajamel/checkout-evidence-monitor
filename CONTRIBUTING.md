# Contributing

Use a separate local branch and a project-local dependency environment. Read the runbook and limitations before collecting evidence. Keep public collection disabled in V1. No dependency lifecycle hook may launch the application or tests.

Changes should include a concrete behavior description, relevant authored assertions and explicit verification status. Run tests only with separate local authorization and the source-bound session. Never remove a test or weaken isolation to claim success. Preserve failed observations and distinguish static analysis from runtime/visual checks.

Do not contribute customer evidence, secrets, environment fonts, browser profiles or private orchestration records. Retain licenses, the ASVS data attribution and visible concept labels. Do not add automatic push/PR/scheduled CI, deployment, telemetry, external fonts or paid services without an explicit scope decision. Publication and LinkedIn posting require their own authorization.
