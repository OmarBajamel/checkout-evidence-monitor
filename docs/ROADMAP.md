# Roadmap and completion criteria

[Documentation](README.md)

This is an evidence-led alpha roadmap, not a delivery-date promise.

| Stage | Current state | Required evidence before closing |
|---|---|---|
| Evidence engine and isolated synthetic LAB | Implemented; historical v0.1.0 verification available | Regression results for the current source |
| Signal and operational workflows | Implemented; current runtime review pending | Keyboard/reflow/error-state checks and a complete review task |
| New PILOT boundary | Implemented; execution unverified | Separately authorized staging checks for scope, DNS, gateway, quotas, expiry and cleanup |
| Research reproducibility | Protocol and fixtures available | Current-source repeated experiment with partial/failed outcomes retained |
| Operator usefulness | Study protocol authored; no participants | Observed tasks and recorded interpretation errors without invented results |
| Supported store pilot | Pending | Named authority, compatible bounded journey and a documented review cycle |

The next supported milestone is a verified local review cycle: configure, observe, compare, interpret and record a decision. Passing static builds is one input; it does not complete this milestone.

Hosted accounts, external notifications, arbitrary checkout automation, authenticated sessions, payments and a translated application UI require separate design/scope decisions. English and Arabic documentation are maintained now.

See [evaluation](EVALUATION_V1_1.md), [limitations](LIMITATIONS.md) and [contribution guidance](../CONTRIBUTING.md).
