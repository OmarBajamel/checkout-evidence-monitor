# مصطلحات المشروع

[الرئيسية بالعربية](../../README.ar.md) · [الإعداد](GETTING_STARTED.md)

| المصطلح | المقابل المستخدم | المعنى في المشروع |
|---|---|---|
| Evidence | الأدلة | الملاحظات المحتفظ بها وحدودها؛ لا تعني إثبات الأمان |
| Baseline | السجل المرجعي | زيارة محفوظة تُستخدم مرجعًا للمقارنة |
| Candidate | سجل المقارنة | الزيارة التي تُقارن بالسجل المرجعي |
| Grant | تفويض محدد النطاق والمدة | إقرار المشغّل بالوجهات والإجراءات المسموحة وفترتها |
| Partial observation | رصد غير مكتمل | نتيجة تحتفظ بحدود الرؤية، وليست نتيجة نظيفة |
| Provenance | مصدر السجل وطريقة جمعه | تمييز الجمع عن الاستيراد أو الأمثلة الاصطناعية |
| Integrity | سلامة الأدلة | توافق البصمات والبايتات المخزنة؛ لا يثبت أصالة الخادم |
| Cadence | وتيرة الزيارات | الفاصل الزمني المطلوب عندما يكون العامل المحلي نشطًا |
| Sanitized export | تصدير بعد تنقيح البيانات | حزمة مراجعة تقلل البيانات الحساسة وفق سياسة محددة |
| Unknown | غير معروف | لا تكفي الأدلة للحكم |
| Runtime verification pending | التحقق التشغيلي معلق | كتابة المصدر أو نجاح البناء لا يثبت السلوك أثناء التشغيل |

تبقى الأوامر والمسارات وأسماء الحقول وأزرار الواجهة مطابقة للنص الإنجليزي. واجهة التطبيق الحالية إنجليزية، ولا يدّعي هذا التوثيق وجود واجهة عربية أو تحقق من دعم RTL.
