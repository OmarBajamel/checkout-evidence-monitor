# 0.2.0 alpha — Signal and local monitoring

Release tag: `v0.2.0-alpha.0` · Python package: `0.2.0a0` · UI package: `0.2.0-alpha.0`.
Published as a prerelease on October 3, 2026.

**Implemented; runtime verification pending.** This is an experimental source release. Static/build checks passed; current UI, monitoring, migration, isolation and merchant compatibility are not yet verified.

## Added
- Signal identity and four connected evidence-review screens.
- Guided paused-target, journey, grant and cadence setup.
- Independent navigation-only public PILOT collector with an inspected browser/proxy boundary.
- Durable local queue, pause/cancel/recovery, missed-window and expiry notices.
- In-app inbox, append-only review decisions and sanitized comparison/review export.
- Prespecified synthetic reproduction, pilot-control and operator-task protocols.
- English and Arabic README/setup documentation, design gallery, upgrade notes and contribution templates.

## Retained boundaries
The ordinary workbench starts no collector. Monitoring needs an explicitly started local worker and valid scoped authority. PILOT supports public guest GET/HEAD observations only: no sign-in, form input, cart mutation, orders or payments.

A new script is not necessarily malicious. Missing or incomparable evidence stays unknown. No compliance, universal coverage or production-readiness claim is made.
