## Documentation languages

English is the canonical technical text. The Arabic README, setup guide and glossary are maintained alongside it. Commands, API paths and UI labels remain exact English identifiers in both languages. Arabic documentation does not imply a translated application or verified RTL interface.

Corrections in either language are welcome through an issue or pull request. Keep security limits, version numbers and verification dates synchronized across translations.
